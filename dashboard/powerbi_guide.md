# Power BI Dashboard — Build Guide

This guide reconstructs the FanSphere AI dashboard from the `fansphere_ai`
PostgreSQL database. Building time: ~30–45 minutes.

---

## 1. Connect to the database

1. **Home → Get data → PostgreSQL database**
2. Server: `localhost`, Database: `fansphere_ai`
3. Data connectivity: **Import**
4. Load the following objects:
   - `matches`
   - `fan_sentiment`
   - `engagement_metrics`
   - `v_executive_overview` (view)

---

## 2. Model relationships

| From | To | Cardinality | Direction |
|---|---|---|---|
| `matches[match_id]` | `engagement_metrics[match_id]` | 1 : 1 | single |
| `matches[match_id]` | `fan_sentiment[match_id]` | 1 : * | single |

Add a date table:

```DAX
DateTable =
ADDCOLUMNS (
    CALENDAR ( DATE ( 2020, 1, 1 ), TODAY () ),
    "Year",       YEAR ( [Date] ),
    "Month",      FORMAT ( [Date], "MMM" ),
    "MonthNum",   MONTH ( [Date] ),
    "Quarter",    "Q" & FORMAT ( [Date], "Q" )
)
```

Mark as date table, then connect `DateTable[Date]` to:
- `matches[match_date]`
- `fan_sentiment[posted_at]` (truncate to date in Power Query)

---

## 3. DAX measures

Create a `_Measures` table and paste:

```DAX
-- Headline KPIs ----------------------------------------------------------
Total Engagement      = SUM ( engagement_metrics[engagement_score] )
Avg Excitement Index  = AVERAGE ( engagement_metrics[excitement_index] )
Avg Match Hype        = AVERAGE ( engagement_metrics[match_hype_score] )
Active Fans           = DISTINCTCOUNT ( fan_sentiment[external_id] )

-- Sentiment --------------------------------------------------------------
Mean Sentiment        = AVERAGE ( fan_sentiment[sentiment_score] )

Positive Count =
CALCULATE (
    COUNTROWS ( fan_sentiment ),
    fan_sentiment[sentiment_label] = "positive"
)

Negative Count =
CALCULATE (
    COUNTROWS ( fan_sentiment ),
    fan_sentiment[sentiment_label] = "negative"
)

Fan Sentiment Score =
DIVIDE (
    [Positive Count] - [Negative Count],
    COUNTROWS ( fan_sentiment )
)

-- Top match ranking (used on Page 3) ------------------------------------
Match Rank =
RANKX (
    ALL ( matches[match_id] ),
    [Total Engagement],
    ,
    DESC,
    DENSE
)
```

## 4. Theme

**View → Themes → Browse for themes** — paste the JSON below as
`fansphere-dark.json`:

```json
{
  "name": "FanSphere Dark",
  "background": "#0E1117",
  "foreground": "#E6E8EB",
  "tableAccent": "#1FB6FF",
  "dataColors": ["#1FB6FF", "#FF5C8A", "#8C7AE6", "#2ED573", "#FFA502", "#7F8FA6"],
  "good": "#2ED573",
  "neutral": "#7F8FA6",
  "bad":  "#FF5C8A"
}
```

Typography: **Segoe UI Semibold** for titles, **Segoe UI** for everything else.
Set page background to `#0E1117`, card backgrounds to `#1A1F2B`.

## 5. Page-by-page build

### Page 1 — Executive Overview

| Visual | Type | Field(s) |
|---|---|---|
| KPI tile — Total Engagement | Card | `[Total Engagement]` |
| KPI tile — Fan Sentiment Score | Card with conditional colour (good/bad) | `[Fan Sentiment Score]` |
| KPI tile — Avg Match Hype | Card | `[Avg Match Hype]` |
| KPI tile — Active Fans | Card | `[Active Fans]` |
| Engagement trend | Line chart | Axis: `DateTable[Date]`, Value: `[Total Engagement]` |
| Top 5 matches | Bar chart | Axis: `matches[home_team] & " vs " & matches[away_team]`, Value: `[Total Engagement]`, Filter: `[Match Rank] ≤ 5` |

### Page 2 — Fan Sentiment

| Visual | Type | Field(s) |
|---|---|---|
| Mean sentiment over time | Line chart | Axis: date, Value: `[Mean Sentiment]` |
| Positivity vs Negativity | Stacked column | Axis: date (week), Values: `[Positive Count]`, `[Negative Count]` |
| Emotion mix | Donut | Legend: `fan_sentiment[emotion]`, Value: count |
| Reaction spikes | Area chart | Axis: date, Value: count of sentiment rows; mark goals as annotations |

### Page 3 — Match Engagement

| Visual | Type | Field(s) |
|---|---|---|
| Match table | Table | match label, competition, `excitement_index`, `match_hype_score`, `engagement_score` — sorted desc |
| Excitement vs Hype | Scatter | X: `excitement_index`, Y: `match_hype_score`, size: `comment_volume`, colour: `is_rivalry` |
| Top matches | Horizontal bar | as Page 1 but top 10 |

### Page 4 — Fan Segments

Import `outputs/fan_segments.csv` (generated by the pipeline) as `fan_segments`.

| Visual | Type | Field(s) |
|---|---|---|
| Segment sizes | Donut | Legend: `segment`, Value: count |
| Behaviour comparison | Clustered bar | Axis: `segment`, Values: avg `comment_frequency`, avg `engagement_activity`, avg `sentiment_volatility` |
| Segment scatter | Scatter | X: `comment_frequency`, Y: `engagement_activity`, colour: `segment` |

---

## 6. Tips for the executive feel

- Keep each page to **6 visuals or fewer**.
- Lock alignment to an **8 px grid**.
- Subtitles in `#7F8FA6`, titles in white.
- One single accent colour per page; reserve `#FF5C8A` for negative deltas only.
- Hide the page tabs — use a **navigation pane bookmark strip** at the top.
